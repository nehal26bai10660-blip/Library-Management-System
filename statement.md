## Functional Requirements

The system should provide the following functions:

❁ Add a new book with title and author

❁ Remove a book from the library

❁ Search for a book by title

❁ Display all books in the library

❁ Display only available books

❁ Borrow an available book

❁ Return a borrowed book

❁ Prevent duplicate books from being added

❁ Validate empty book titles and author names

❁ Handle invalid menu input

## Non-Functional Requirements

### Usability

❁ The system should provide a simple menu-driven interface.

❁ Users should be able to understand and select operations easily.

### Reliability

❁ The system should handle invalid menu input without crashing.

❁ The system should prevent empty book titles and author names.

### Maintainability

❁ The program should be divided into separate modules and classes.

❁ The code should be organized so that individual components can be modified easily.

### Performance

❁ The system should perform basic book operations quickly for a small library collection.

❁ The system should use an in-memory list to manage books efficiently.
